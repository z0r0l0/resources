# 🔧 工具合集

> 一键安装与环境初始化

## 使用方法

```bash
# 完整安装开发环境
bash ~/resources/tools/one-click-setup.sh

# 或按需使用 scripts/ 下的细分脚本
```

## 内容

| 脚本 | 说明 | 路径 |
|------|------|------|
| 一键安装 | 安装 gh、bat、fzf、htop 等开发工具 | `tools/one-click-setup.sh` |
| 环境检查 | 查看系统健康状态 | `scripts/system/check-env.sh` |
| 一键更新 | 更新 apt/pip/npm/Hermes | `scripts/system/update-all.sh` |
